# proto-forge v0.4.0 — production grade: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the overlay layering guarantee real for stacks (not just single overlays), make "fully tested" mechanically provable, give the component library a browser-verified test suite, and make the plugin self-contained.

**Architecture:** Overlays move to the browser top layer (`<dialog>.showModal()`, Popover API) with a React-context `OverlayStack` owning dismiss order, refcounts and the no-top-layer fallback; the `own | radix` provider switch is retired. A declarative case registry (`src/harness/cases.ts`, pure data) drives both documentation screenshots and a generated Playwright suite. Coverage goes to 100 % on every glob behind a locked exclusion list, an ignore registry and a Stryker mutation gate. The normative register (`references/requirements.md`) ships in-repo behind a citation gate that fails on a dangling citation, an unenforced rule or an unmotivated gate.

**Tech stack:** React 19, TypeScript 5.9, Vite 6, Vitest 3 + jsdom 26, Playwright 1.61 + `@axe-core/playwright`, Stryker (`@stryker-mutator/core` + `vitest-runner`), zod 3, Dexie 4, ESLint 9 flat config, pnpm 10, Node 22.

**Source of truth:** `docs/specs/2026-08-12-production-grade-design.md`. Section references below (`§4.1`, `D3`, …) point there.

## Global Constraints

Copied verbatim from the spec and the template's existing rules. **Every task's requirements implicitly include this section.**

- **Node** `>=22 <23`; **pnpm** `10.11.0`. Package manager is pnpm, never npm/yarn.
- **No first-party mocking.** `vi.mock`/`vi.doMock` of a relative, `@/` or `@jj/` path is banned anywhere in the tree (`stub:scan` enforces). Mock data means typed fixture factories.
- **No banned markers in production code:** `TODO`, `FIXME`, `XXX`, `HACK`, `not implemented`, `unimplemented`, `lorem ipsum` (`stub:scan`). This includes comments. Write the code instead.
- **Every user-visible string is a `t()` key**, as JSX text *and* as a prop (`title`, `label`, `emptyLabel`, `errorMessage`, … and any `*Label`/`*Text`/`*Message`/`*Title`/`*Error` suffix). `packages/proto-ui/**` owns **no copy of its own** — it takes strings as required props.
- **Every interactive and semantic element carries a unique `data-testid`**, interpolated inside `.map()`. Primitives take `data-testid` as a **required** prop.
- **`tokens.layer.{overlay,modal,popover,toast,tooltip}` may be read only in `packages/proto-ui/src/overlay/OverlayStack.tsx`.** Everything else consumes `slot.fallbackZIndex`. No numeric `zIndex` anywhere outside `tokens.ts`.
- **Coverage floor after Task 24:** `statements/branches/functions/lines = 100` on every glob. Exactly three exclusions (§7.1). Never add a fourth; never lower a threshold.
- **Every `v8 ignore` carries** `-- <reason> [covered-by: <harness case id>]` (Task 25).
- **ESLint ceilings after Task 27:** `max-lines` 200, `max-lines-per-function` 60, `complexity` 8, `max-depth` 3, `max-params` 3.
- **English only in code** (`consistency` fails on non-Latin scripts outside locale catalogues).
- **ADR anchors:** exactly `// @adr NNN - <what>`; the ADR must exist and be `accepted`. Every accepted ADR ≥010 must be anchored ≥1× in production code.
- **Commits:** Conventional Commits. The plugin repo has no `commit-lint`; the template does. Commit after every task, never with `--no-verify`.
- **Two repos-in-one:** scripts under `/scripts/**` are **plugin-level** (plain Node, no deps, run from repo root). Scripts under `/template/scripts/**` are **prototype-level** and run with the template as cwd. Never import across that boundary.

import { test, expect } from "@playwright/test";
import AxeBuilder from "@axe-core/playwright";
import { cases } from "../src/harness/cases";
import { isTopmost, exceedsClippingAncestor, tabOrder, focusedTestid, hasVisibleFocusRing } from "./support/overlay";

for (const c of cases.filter((x) => x.kind !== "structural")) {
  test.describe(c.id, () => {
    test.beforeEach(async ({ page }) => {
      const errors: string[] = [];
      page.on("console", (m) => m.type() === "error" && errors.push(m.text()));
      page.on("pageerror", (e) => errors.push(e.message));
      await page.goto(`/harness.html#/${c.id}`);

      for (const key of c.interactions?.press ?? []) await page.keyboard.press(key);
      (test.info() as { errors?: string[] }).errors = errors;
    });

    test("has no serious or critical accessibility violation", async ({ page }) => {
      if (c.axe?.skip !== undefined) test.skip(true, c.axe.skip);
      const { violations } = await new AxeBuilder({ page }).analyze();
      expect(violations.filter((v) => v.impact === "serious" || v.impact === "critical")).toEqual([]);

    });
  });
}
